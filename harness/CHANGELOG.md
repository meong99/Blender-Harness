# 변경 이력

- `.blender-harness/` 격리 설치와 기존 프로젝트 AGENTS.md 관리 구역 병합. 원문과 사용자 제작 결과 보존.
- 파일별 배포 기준 해시 비교, 로컬 단독 변경 보존, 동일 파일 양쪽 변경 충돌 시 전체 적용 중단, 백업과 쓰기 오류 복원.
- GitHub 정식 Release 확인/다운로드/해시 검사, 저장소 고정, 버전 역행 차단. check-update/update와 로컬 ZIP 패치 지원.
- PACKAGE.json을 포함한 bundle과 태그 기반 GitHub Release workflow. 하네스 밖의 모델·사진·세션 로그는 배포 제외.
- 모델링 품질 규칙은 v1.1 유지. 설치 병합은 파일/관리 구역 단위이며 자연어 규칙이나 코드의 의미적 자동 병합은 아님.

## 1.1.0 — 2026-10-04

사용자가 시안과의 미세한 차이와 원래 연속 표면에 남는 부품 경계를 지적하여 추가했다. 실제 효과와 설계 가설을 구분하기 위해 합성 정답 기반 회귀 테스트를 수행한다.

- 새 실행에 에이전트가 작성한 quality-plan을 필수로 저장하고 해시를 고정한다.
- 연속 표면의 평가된 메시 연결 성분/닫힘 검사, 분리 부품 존속 검사를 추가한다.
- 명시적 fuse_voxel 도우미를 제공한다. 분리 그룹을 함께 합치려 하면 사전에 거부한다. 전역 자동 remesh는 없다.
- 고정 카메라 시안 비교와 바운딩 박스 기준점의 픽셀 오차, 접합부 확대, HTML 검수 자료를 추가한다.
- 수치 실패의 pass 처리를 차단하고 표면/시안 검수 기록을 요구한다. 수치 통과 후에도 에이전트 시각 검수가 필요하다.
- 몸체의 국소 수정본에서 detail을 계속할 수 있도록 단계 계보를 처리한다.
- 최종에는 검수된 확대 프리뷰를 재사용한다. 단계마다 실제 실행 코드 해시를 기록한다.

확인 범위: 알려진 폭 오차와 분리 셸을 가진 단순 소품의 검출·수정, 분리 부품 보호, 저장 재열기. 복잡한 피규어/실사 사진에 대한 반복 품질 향상이나 작업 시간 단축은 미검증이다. 접선/곡률 연속성, 자기 교차, 실제 가동 간격을 자동으로 증명하지 않는다. 바운딩 박스 기준점은 전체 실루엣 유사도 점수가 아니다.

호환: v1.0 ZIP과 역사적 산출물은 보존한다. 새 실행은 --quality-plan과 review의 두 검수 인수가 필요하며 에이전트가 제공한다. Blender 5.2.2 LTS / Windows에서 검사한다.
